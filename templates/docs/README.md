# Documentation

This folder is both the documentation and the memory of the AI pipeline.

| Path | What it is | Who writes it |
| --- | --- | --- |
| `features/<feature>/README.md` | Current behaviour of one feature, as proven in code | Coding agent updates it with every change |
| `features/<feature>/tickets/<id>.md` | The plan for one ticket: scope, acceptance checks, risks | Pipeline, from the plan agent's plan.json |
| `features/<feature>/CHANGELOG.md` | One line per checked-in ticket | Pipeline |
| `memory/INDEX.md`, `memory/lessons/` | Mistakes found on redo, so they are not repeated | Agent writes lesson.json, pipeline files it |
| `FEATURES.md` | Index of every feature | Generated by `agent-pipeline docs index` |

Agents are told which feature docs and lessons to read first. The pipeline finds them from the ticket text
using each README's front matter (title, keywords, paths). Keep the keywords accurate.
